# LocalStudy: границы учебного проекта

LocalStudy — адаптивный трекер обучения. Пользователь выбирает курс и цель,
формирует недельный план, проводит учебные сессии, решает задания и получает
объяснимые рекомендации на основе прогресса.

## Учебная цель проекта

Каркас нужен для последовательной практики full-stack разработки:

- слоистый backend на FastAPI;
- явные команды и запросы приложения;
- репозитории и транзакционные границы;
- собственные логирование и обработка ошибок;
- Vue 3 SPA с типизированным API-клиентом, Router и Pinia;
- проверяемый контракт из 29 прикладных HTTP-операций.

## Что входит в первую версию

1. Каталог курсов и пререквизитов.
2. Персональный учебный план и прогноз завершения.
3. Календарь учебных сессий и переходы их состояний.
4. Практические задания, подсказки и история попыток.
5. Аналитика прогресса и рекомендации по следующим шагам.

## Что намеренно не входит

- авторизация и роли;
- интеграция с внешними LMS;
- ML-модель рекомендаций;
- платежи, сертификаты и социальные функции;
- шаблонные приватные пакеты `backend-auth`, `backend-shared` и
  `fastapi-observability-logging`.

В первой версии используется один демонстрационный профиль учащегося. Позже его
идентификатор можно заменить контекстом собственной авторизации, не меняя
прикладные сценарии.

## Архитектурные правила

- Backend: `api -> application -> domain`, инфраструктура реализует порты
  приложения.
- Frontend: `app`, маршрутные модули в `pages`, переиспользуемые части в
  `shared`.
- Контроллеры не содержат бизнес-правила и не обращаются к хранилищу напрямую.
- Компоненты Vue не вызывают `fetch` напрямую.
- Для каждого экрана определено одно основное действие.
- Технические маршруты (`/health`, OpenAPI) не считаются прикладными методами.
